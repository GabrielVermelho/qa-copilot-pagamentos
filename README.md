Projeto de portfólio: testes e análise de falhas em fluxos de pagamento simulados, com apoio de IA
# QA Copilot para Pagamentos

Projeto de portfólio de Gabriel Vermelho Ferreira.

## Objetivo
Simular um fluxo de pagamento em maquininha/totem e testar o que acontece
quando algo dá errado (pagamento negado, falha de comunicação, transação
fora de rota), usando testes automatizados e IA para analisar as falhas.

## Status
Em construção. Todos os dados e sistemas deste projeto são fictícios.

## O que será construído
- [ ] Simulador de pagamento (API de mentirinha, ou "mock")
- [ ] Testes automatizados dos cenários de sucesso e de falha
- [ ] Execução automática dos testes a cada mudança (CI)
- [ ] Agente de IA que lê o registro de erros e sugere a causa
